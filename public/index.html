Ruční hra

Zápas z webu

Vyber hru z programu produkce — výsledek se po konci hry sám zapíše na web. Bez výběru se hra na web neposílá.

Napojení na web

Tokeny produkcí vystaví admin v adminu webu: System / Integrations → Production Agent. Agent použije token produkce, kterou vybereš v horní liště. Ukládají se jen v tomhle počítači.

Výběr produkce

Vyber produkci pro dnešní vysílání. Agent podle ní načte program a hry bude zakládat sám.
